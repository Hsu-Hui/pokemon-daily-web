## Why

任務待辦目前把日常田野調查獎勵與需要追蹤完成度的任務混在一起，且勾選後重畫畫面會打斷使用者所在位置；手動任務輸入錯誤後也只能刪除重建。這些問題會造成任務紀錄不可靠、操作中斷，以及已完成任務仍出現在總覽提醒中的誤導。

## What Changes

- 在「任務待辦」新增獨立的「日常田野調查獎勵」區塊，顯示任務與獎勵但不提供勾選框，也不計入任務進度、完成判斷或提醒。
- 讓每月田野調查任務組保留勾選框，並改成與限時調查相同：勾選第 N 項時，第 1 至 N 項一起勾選；取消第 N 項時，第 N 項之後一起取消。
- 手動新增的任務組提供編輯功能，可修改名稱、結束時間、任務文字與獎勵，沿用新增時的驗證與上限，並保留仍可對應的完成紀錄。
- 勾選、取消勾選、刪除或編輯任務組後，畫面維持使用者原本的垂直捲動位置，不再自動跳回頁首；只有明確切換分頁或換頁時才回到頁首。
- 將「有 N 項變更未儲存／已儲存」與「儲存」按鈕移到「任務待辦」標題同一行的最右側，其他分頁不顯示。
- 修正總覽「快結束了，還沒完成」的通用完成判斷：只要任務待辦已將任務組判定為全部完成，總覽就立即移出該組；不得依賴任務名稱或額外的儲存條件，「小隕星流星雨：獵戶座 2026」僅作為回歸案例。

## Capabilities

### New Capabilities

無。

### Modified Capabilities

- `dashboard`：調整任務待辦的田野調查呈現、手動任務編輯、捲動位置、儲存控制位置，以及總覽完成任務的排除規則。
- `user-progress`：每月田野調查由獨立勾選改為依序勾選，並規範編輯手動任務後完成紀錄的對應方式。

- 前端互動與版面：`gas/App.html`、`gas/Styles.html`、`gas/Index.html`
